To publish:
1. Create a public GitHub repository (for example, devansh-portfolio).
2. Upload index.html and the entire assets folder, preserving the folder structure.
3. Go to Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. After the site works, add a custom domain under Settings > Pages and configure DNS at your domain registrar.

Before publishing:
- Confirm that the school name and biography details are correct and that you are comfortable making them public.
- Only add public social links you control.
- Replace the canonical/structured-data URL with the final domain after it is configured.
- Do not publish your home address, phone number, student ID, timetable, or other private information.

This is a static site and does not need a database or paid API.
